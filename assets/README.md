# Resume Placement Guide

Place your compiled resume PDF in this folder named exactly:
`Mohan_Venkata_Subba_Rao_Resume.pdf`

Both the "Download Resume" buttons and the "Quick View Overview" modal on your portfolio website link directly to this file (`assets/Mohan_Venkata_Subba_Rao_Resume.pdf`).

### Quick Checklist:
1. Export your resume as PDF from Word / Google Docs / LaTeX / Canva.
2. Rename the file to `Mohan_Venkata_Subba_Rao_Resume.pdf`.
3. Copy it into this `assets/` directory.
4. Refresh your website in your browser!
